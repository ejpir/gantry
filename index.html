01 — THE WORKFLOW

A workspace, not a throwaway.

Pull an OCI image. Give it a name. Stop and resume without losing your installed packages or private writable disk.

gantry / CLI examples
# Your image, in its own microVM.
$ gantry start dev -image debian:bookworm-slim
# A persistent sandbox called “dev”.
# Step inside. Make yourself at home.
$ gantry exec dev -- /bin/bash
# Or open the terminal dashboard: gantry tui
# Call it a day. Pick up where you left off.
$ gantry stop dev
$ gantry resume dev

02 / A different kind of lightweight

Less machinery.
More boundary.

Gantry is a standalone Go VMM and CLI. It talks directly to your host’s virtualization backend. No Docker, containerd, QEMU, or libkrun required.

Each sandbox gets a private Linux kernel. Guest-facing work runs in confined host workers where supported, with optional gVisor inside the VM.
