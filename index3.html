Your containers.Their own kernel.

Run OCI images in Linux microVMs. One binary, a private kernel per sandbox, and no Docker required.

A persistent workspace
# Create a sandbox
gantry start dev -image alpine:latest

# Open a shell
gantry exec dev -- /bin/sh

# Exit the shell, then stop. Resume later.
gantry stop dev
gantry resume dev

Keep your workspace

Named sandboxes keep their writable disks between sessions. Share a project directory when you need host files; leave the rest on the host.

One binary.
Role-separated workers.

A trusted supervisor manages lifecycle, credentials, and delegated access. In split mode, guest-facing work runs in role-specific processes with narrowly scoped capabilities and platform-specific confinement.

Use -process-isolation=required to refuse startup unless the required isolation properties are verified.
