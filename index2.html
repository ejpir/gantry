02 / Architecture

Runtime architecture

A standalone Go VMM and CLI, connected directly to your host’s virtualization backend. No Docker, containerd, QEMU, or libkrun required.

01 A kernel for every sandbox

Your OCI workload runs under a private Linux guest kernel, with crun by default and optional gVisor inside the VM.

02 Separate guest-facing workers

The host supervisor coordinates VMM, network, and shared-filesystem workers. Guest-facing work is confined where the platform supports it; the details differ by host.

03 Native host virtualization

Linux uses KVM on x86-64 and arm64. Apple silicon Macs use Hypervisor.framework on macOS 13+. Windows x86-64 uses WHPX and remains experimental.

Architecture documentation

03 / Get started

Install Gantry

Download Gantry for your host, then run an OCI image. First use fetches verified guest assets and the image; cached assets are reused on later starts.

Hardware virtualization is required. Inside another VM, you’ll need nested virtualization.
